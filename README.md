# Aurora • Studio (Preview edition)

Same layout, popup, floating button, saved setups, reset, debug log and history as the other Aurora studios.
The one difference: preview is locked on and cannot be turned off. A task visits each page in order, waits the pace you set,
and reports what it WOULD do. Nothing is ever clicked, reacted to, commented on, followed, joined or shared.

Install: unzip so you get the `aurora-studio` folder, then chrome://extensions → Developer mode → Load unpacked → pick that folder.
Unzip it into its own folder, not into another extension's folder.
